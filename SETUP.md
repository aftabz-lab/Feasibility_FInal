# Remove the Values-only PDF label

1. Extract this ZIP.
2. Open https://github.com/aftabz-lab/Feasibility_FInal on the main branch.
3. Upload and replace ONLY pdf-exporter.js, app.js, and index.html in the repository root.
4. Commit the changes and wait for the Pages deployment to finish.
5. Open the dashboard, press Ctrl+Shift+R, and generate new PDF downloads.

The Values-only subtitle has been removed from all three pages of both Download 3-page PDF and Management PDF, including the slightly different subtitle on page 3. Existing PDFs must be generated again to apply the change.

The three PDF subtitle strings are the only content changes. The app.js and index.html changes update browser cache versions. All other PDF text, calculations, fonts, layout, page dimensions, signatures, signatory rules, Excel behavior, and dashboard features remain unchanged. The current no-source-workbook and Opened By updates are preserved.
